# Deep-Learning-Projects- + Computer Vision 

1️⃣ Chest X-Ray Disease Detection

Problem:
Detect lung diseases from chest X-ray images using AI.

What it does:

Takes a chest X-ray image as input

Predicts whether the image shows a disease or normal condition

Tech Used:

Convolutional Neural Networks (CNN)

TensorFlow / Keras

Image preprocessing & normalization

Learning Outcome:

Medical image classification

Handling real-world healthcare datasets

Model training and evaluation

2️⃣ Object Recognition (CIFAR-10)

Problem:
Classify everyday objects from small images.

What it does:

Classifies images into 10 categories
(airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck)

Tech Used:

Custom CNN architecture

CIFAR-10 dataset

Softmax classification

Learning Outcome:

Multi-class image classification

Building CNNs from scratch

Improving accuracy through model depth

3️⃣ Lion vs Tiger Image Classification

Problem:
Differentiate between visually similar animals using AI.

What it does:

Takes an image as input

Predicts whether it is a Lion or a Tiger

Tech Used:

CNN-based deep learning model

Image augmentation

Binary classification

Learning Outcome:

Feature extraction from images

Handling similar visual patterns

Binary classification techniques

Tech Stack

Python

TensorFlow / Keras

NumPy, Pandas

Matplotlib

Flask (for deployment-ready structure)

Note

These projects focus on practical learning, model building, and real-world understanding rather than just accuracy scores.
